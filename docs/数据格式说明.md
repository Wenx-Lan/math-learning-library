# 数据文件写作规范（供内容作者遵循）

本文件是「高中数学学习资源库」内容数据的**唯一格式契约**。所有内容文件必须严格遵循，否则页面会渲染异常。

## 一、文件与命名（已确定，不要改动）

| 文件 | 作用 |
| --- | --- |
| `js/data/manifest.js` | 章节清单（已完成，勿改） |
| `js/data/fig-<章号>.js` | 第 <章号> 章的简图定义 |
| `js/data/k-<章号>-<章名>.js` | 第 <章号> 章「基础知识」数据 |
| `js/data/t-<章号>-<章名>.js` | 第 <章号> 章「题型」数据 |

章号与章名的对应见 `js/data/manifest.js`。

## 二、可用工具（已全局提供）

1. `DSHMath`：数学公式渲染。写成 `\( ... \)`（行内）或 `\[ ... \]`（独立成行），页面会自动渲染。**不要在数据文件里调用它。**
2. `DSHFig`：简图库。
   - 数据文件（`k-*.js`）里插入简图：`DSHFig.use('图id')` 返回 HTML 字符串，直接拼进 `html` 字段；`DSHFig.row([{id:'a'},{id:'b'}])` 并排两张。
   - 简图文件（`fig-*.js`）里定义简图：`DSHFig.add('图id', { title, caption, coord | viewBox, draw })`。
3. 全局对象 `DSHData`：`DSHData.registerKnowledge({...})` / `DSHData.registerTypes({...})`。

## 三、LaTeX 子集（只支持这些写法）

支持的公式写法示例（全部可正常渲染）：

```text
\(x^2-3x+2>0\)            \(a\ne0\)              \(A\subseteq B\)
\(\frac{a+b}{2}\ge\sqrt{ab}\)                   \(\sqrt[3]{abc}\)
\(x_1<x_2\)               \(\log_a N=b\)         \(\sin^2\alpha+\cos^2\alpha=1\)
\(\vec a\cdot\vec b=|\vec a||\vec b|\cos\theta\)
\(\lim_{\Delta x\to0}\frac{f(x_0+\Delta x)-f(x_0)}{\Delta x}\)
\(\sum_{k=0}^{n}C_n^k a^{n-k}b^k\)
\(\begin{cases} x>1 \\ x<3 \end{cases}\)
\(\complement_U A\)   \(\varnothing\)   \(\Rightarrow\)   \(\iff\)   \(\text{当且仅当}\)
```

规则：
- 每个公式都必须用 `\( ... \)` 或 `\[ ... \]` 包裹；**不要**出现裸露的 `^` `_` `\frac` 等。
- 上下标内容超过一个字符必须加花括号：`x_{1}`、`a^{n+1}`。
- 中文写进 `\text{...}` 里才不会被当成变量（例如 `\(\text{仅当}x>0\)`）。
- 集合补集写成 `\(\complement_U A\)`。
- 不支持 `\stackrel`、`\begin{align}` 里的 `&` 对齐以外的复杂环境；矩阵/分段用 `\begin{cases} ... \\ ... \end{cases}`。
- HTML 里写 `<` `>` 要写成 `&lt;` `&gt;`；`\(` 里的不受影响。

## 四、HTML 片段允许的标签

`<p> <ul> <ol> <li> <b> <i> <em> <strong> <code> <table class="tbl"> <thead> <tbody> <tr> <th> <td> <br> <span class="small muted"> <div class="sub-title">`

内联样式请用现成的 class（`.small`、`.muted`、`.sub-title`），不要写自定义颜色。

## 五、`k-*.js` 格式（基础知识）

```js
DSHData.registerKnowledge({
  id: 1,                                   // 章号，必须与文件名一致
  name: '集合',
  group: '必修一 · 集合与逻辑',
  brief: '一句话概括本章地位与核心。',
  sections: [
    {
      title: '一、集合的概念与表示',
      tag: '概念',                          // 可选
      html: '<p>...</p><ul><li>...</li></ul>' + DSHFig.use('c1-venn')
    }
  ],
  proofs: [
    {
      title: '含 n 个元素的集合有 2^n 个子集',
      claim: '证明目标：\(A\) 有 \(n\) 个元素时，子集个数为 \(2^n\)。',
      steps: [
        '第一步……\(x=1\) 时成立。',
        '第二步……由 \(k\) 推 \(k+1\)。'
      ],
      note: '可选的补充说明。'
    }
  ],
  figures: ['c1-venn', 'c1-subset-tree'],  // 本章重点简图（会显示在页首「本章简图」）
  types: ['元素互异性求参数', '交并补运算']  // 本章关联题型名称（可省略）
});
```

要求：
- `sections` 至少 4 节，覆盖**给定大纲的全部基础概念**，并在大纲基础上适度展开（讲清"为什么"）。
- `proofs` 至少 2 条，必须是**真正有推理过程**的证明或推导（如公式推导、结论证明、判定定理证明），不能只是复述结论。
- 每一节的 `html` 里应至少配 1 张简图或一段"读图提示"，做到"图文对应"。
- 公式、符号必须正确无误；例题数据不要写进这里。

## 六、`t-*.js` 格式（题型）

```js
DSHData.registerTypes({
  id: 1,
  name: '集合',
  brief: '本章题型的整体特点与通用策略。',
  types: [
    {
      id: '1-1',                            // 章号-序号
      name: '集合的表示与元素互异性',
      desc: '考查……，常用方法……。',
      points: ['要点一 \(a\\ne0\)', '要点二……'],   // 注意：字符串里的反斜杠要写成 \\
      questions: [
        {
          id: '1-1-1',
          kind: 'choice',                   // 'choice' | 'blank' | 'short'
          stem: '题干……',
          options: ['选项A内容', '选项B内容', '选项C内容', '选项D内容'],
          answer: 'B',                      // 选择题写字母
          answerText: 'B',
          solution: '<p>解析……</p>'
        },
        {
          id: '1-1-2',
          kind: 'blank',
          stem: '（可选，填空题题干）',
          blanks: [
            { before: '集合 \(A\) 中元素个数为 ', answer: '3', after: ' 个。' }
          ],
          answer: '3',
          answerText: '3',
          solution: '<p>解析……</p>'
        },
        {
          id: '1-1-3',
          kind: 'short',
          stem: '题干……',
          answerText: '\(a\\in[0,1]\)',
          solution: '<p>详解……</p>'
        }
      ],
      examples: [
        {
          id: '1-1-ex-1',
          title: '由元素互异性求参数',
          problem: '题干……',
          solution: '<p>解答……</p>',
          note: '可选的方法总结'
        }
      ]
    }
  ]
});
```

硬性要求（会被自检脚本检查）：
1. `types` 数组的**题型名称与顺序**必须与用户提供的大纲"常见题型"小节完全一致（一字不差）。
2. 每个题型 `questions.length` 必须是 **3 或 4**。
3. 每个题型的 4 道题必须**方向各异**：至少覆盖 2 种 `kind`，且不要出现两个几乎相同的题。
4. 每个题型 `examples.length` 必须是 **1 或 2**，且与本节题型直接相关。
5. 每题必须有 `answer`（选择题为字母）、`answerText`（可直接展示的答案，可含公式）、`solution`（含推理过程的详细解析，不得只写"略"）。
6. `id` 必须唯一：题目 `id` 形如 `1-1-3`，例题 `id` 形如 `1-1-ex-2`。
7. 填空题的 `blanks[i].answer` 要写成学生可能输入的规范写法；等价写法可用数组，如 `answer: ['3','x=3']`。
8. 计算必须正确！凡涉及数值，请逐步核算一遍再写入。

## 七、`fig-*.js` 格式（简图）

```js
(function () {
  'use strict';
  if (!window.DSHFig) { return; }
  var add = DSHFig.add, n = DSHFig.n;

  // 方式 A：带数学坐标系（推荐用于函数图）
  add('c1-subset-tree', {
    title: '子集个数',                       // 图内小标题
    caption: '图注：说明这张图要看什么。',     // 显示在图下方
    coord: { x: [-1, 5], y: [-1, 5], grid: 1, pad: 0.4 },   // 数学坐标范围（y 轴向上）
    draw: function (h) {
      return [
        h.axes({ origin: true, ticks: true, grid: false, xlabel: 'x', ylabel: 'y' }),
        h.fn(function (x) { return x * x - 2 * x; }, {}),
        h.dot(1, -1, { label: '(1,-1)', dy: -0.35 }),
        h.seg(0, 0, 2, 3),
        h.vline(1, { from: -1, to: 2 }),
        h.text(2.2, 3, '直线', 'lbl--sm')
      ];
    }
  });

  // 方式 B：自由绘图（几何图形、韦恩图、流程图等）
  add('c1-venn-ops', {
    title: '集合运算',
    caption: '阴影部分为 \(A\\cap B\)。',
    viewBox: '-3.4 -2.4 6.8 4.8',
    draw: function (h, n) {
      return [
        n('circle', { class: 'shape', cx: '-0.85', cy: '0', r: '1.7' }),
        n('circle', { class: 'shape', cx: '0.85', cy: '0', r: '1.7' }),
        n('text', { class: 'lbl', x: '-2.1', y: '1.9' }, 'A')
      ];
    }
  });
})();
```

### 绘图 API（`h`）

| 调用 | 说明 |
| --- | --- |
| `h.axes({origin, ticks, grid, xlabel, ylabel})` | 坐标轴（含刻度/网格，可省参数） |
| `h.fn(f, {from, to, cls, steps})` | 函数曲线，`f(x)` 返回数值 |
| `h.poly([[x,y],...], {cls, close, fill})` | 折线/多边形 |
| `h.seg(x1,y1,x2,y2,{cls})` | 线段 |
| `h.arrow(x1,y1,x2,y2,{cls})` | 带箭头线段 |
| `h.circle(cx,cy,r,{cls})` | 圆 |
| `h.dot(x,y,{label,dx,dy,solid,r})` | 点（可带标注） |
| `h.text(x,y,文本,cls,anchor)` | 文字（数学坐标，anchor: start/middle/end） |
| `h.vline(x,{from,to,cls})` / `h.hline(y,{from,to,cls})` | 虚线辅助线 |
| `h.rightAngle(x,y,'left'|'right',{size})` | 直角符号 |
| `h.angleArc(x,y,r,起始角,终止角)` | 角弧 |
| `h.region([[x,y],...])` | 填充区域 |

`cls` 可选值：`curve`（实线曲线，默认）、`curve--soft`（虚线曲线）、`ax`（坐标轴/普通线）、`hl`（虚线辅助线）、`shape`（几何体面）、`shape--dark`（被遮挡面）、`arc`（弧）。样式已由 CSS 定义，**不要写内联颜色**。

> 注意：`draw: function (h)` 的第二个参数是 `n`（方式 B 用）；用方式 A 时只需 `h`。

### 可用的数学命令一览（渲染器已支持，实测通过）

| 类别 | 可用写法 |
| --- | --- |
| 分式/根式 | `\frac{a}{b}`、`\dfrac`、`\tfrac`、`\sqrt{x}`、`\sqrt[3]{x}`、`\sqrt[n]{a}` |
| 上下标 | `x^{2}`、`x_{1}`、`C_n^m`、`\sum_{k=0}^{n}`、`\lim_{x\to0}`、`\int_0^1` |
| 集合与逻辑 | `\in`、`\notin`、`\subset`、`\subseteq`、`\cup`、`\cap`、`\varnothing`、`\complement_{U}`、`\setminus`、`\forall`、`\exists`、`\Rightarrow`、`\iff` |
| 关系符 | `\le`、`\ge`、`\ne`、`\approx`、`\equiv`、`\perp`、`\parallel`、`\pm`、`\times`、`\div`、`\cdot` |
| 函数与记号 | `\sin`、`\cos`、`\tan`、`\log`、`\ln`、`\lim`、`\max`、`\min`、`\vec a`、`\overrightarrow{AB}`、`\overline{AB}`、`\bar x`、`\hat y` |
| 字体 | `\mathbf{R}`、`\mathbb{R}`、`\mathrm{d}`、`\text{中文}` |
| 结构 | `\begin{cases} a \\ b \end{cases}`、`\left( \right)`、`\quad`、`\qquad` |

> 注意：`\mathbf` / `\mathbb` **必须带花括号**（写成 `\mathbf{R}`，不要写 `\mathbf R`）；
> 不支持 `\big`、`\tag`、`\stackrel`、`\substack`、`\begin{align}`（用 `\begin{cases}` 代替多行）；
> 需要中文时放进 `\text{...}`。

### 最容易踩的三个坑

1. **反斜杠数量**：源码里必须写 `'\\( ... \\)'`（即运行时为 `\( ... \)`）。写成 `'\( ... \)'` 会让 `\t`、`\n`、`\f` 等变成控制字符，公式直接损坏（`\triangle` 会变成 TAB + "riangle"）。写完务必用 `node tools/check.js` 与 `node tools/_tmp/renderall.js` 自检——后者会真实渲染每一个公式。
2. **定界符成对**：每个 `\(` 必须配 `\)`；`\[` 配 `\]`。`\left(` 必须配 `\right)`，不要在 `\left(`/`\right)` 里再塞 `\)`。
3. **HTML 实体**：正文里的 `<`、`>` 写成 `&lt;`、`&gt;`（公式内部写 `&gt;` 也能正常渲染）。

### 答案字段的小约定

`answer` / `answerText` / `blanks[].answer` 可以只写公式本体（例如 `'\\sqrt{3}'`、`'\\frac{\\sqrt{6}}{3}'`）。
页面会在渲染前自动补上 `\( \)`，因此**不必**手写定界符；纯文字（如 `'2x+y-5=0'`、`'见解析'`）原样显示。

## 八、质量要求

- 内容必须符合人教版高中数学的表述习惯，用词严谨。
- 每章至少 4 节概念 + 2 条证明 + 每个题型 3~4 题 + 1~2 例题。
- 数学结论、计算、选项设置必须**正确且互斥**（选择题要有明确唯一答案，错误选项要有"典型错误"的来源）。
- 不做与本章无关的花哨内容；不要出现"以上内容来自网络"之类的文字。
- 文件必须能单独加载成功（不能有语法错误），且加载后 `DSHData.knowledge[章号]` / `DSHData.types[章号]` 有值。
