检查项对照表

A 数据文件是否全部加载成功（onerror 记录）
B 18 章 registerKnowledge：id 正确、name 非空、sections ≥ 4、proofs ≥ 2（每条 title + ≥2 steps）
C 18 章 registerTypes：types ≥ 3，每个题型有 name / questions / examples
D 每个题型 questions.length ∈ {3,4}；kind 至少 2 种；kind 只能是 choice/blank/short
E 每题有 stem / answer / answerText（或 answer 数组）/ solution（去标签后 ≥ 15 字符，不得只写“略”）
F choice 有 4 个非空 options 且 answer ∈ {A,B,C,D}；blank 有非空 blanks 且每个 blank 有 answer
G 题目 id 形如 N-M-K、例题 id 形如 N-M-ex-K，且整章唯一
H 每个题型 examples.length ∈ {1,2}，每条例题有 problem 与 solution
I 全部 DSHFig.use('x') / DSHFig.row([{id:'x'}]) 引用的图 id 都存在于 DSHFig.registry
J 公式配对：所有字符串中 \( 与 \) 数量相等、\[ 与 \] 数量相等
K 章节顺序与 manifest 的 DSHData.order 为 1..18 连续
L 数学渲染冒烟测试：每章第一章第一题的 stem + solution 经 DSHMath.render 后产生 <math> 且无异常
